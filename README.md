# 외환전문역 암기왕 v4

## 1종과 2종을 완전히 분리
- Ⅰ종: 외환관리실무 / 외국환거래실무 / 환리스크관리
- Ⅱ종: 수출입실무 / 국제무역규칙 / 외환관련여신
- 상단에서 즉시 전환
- 학습기록·시험일·오답을 종목별로 따로 저장
- 50/30/20 배점 구조를 기본 출제 비율로 사용

## 핵심 기능
- 오늘의 학습 자동 출제
- 시험일 기반 학습량 자동 조정
- 영어단어 암기장 스타일 핵심카드
- 10초 암기
- 숫자·기관·기한 모드
- 오답 반복
- 시험 직전 모드
- 9:16 배경화면 PNG 생성
- 공개 웹 자료 실시간 검색/연결
- 기기 간 학습기록 동기화 코드
- PWA 홈 화면 설치
- 오프라인 카드 학습

## 데이터
기존 생성 카드 575개를 1종/2종 전용으로 나누어 사용합니다.
실제 기출인지 확인되지 않은 카드는 '암기카드', 샘플문제는 별도 표시합니다.
